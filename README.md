# Invitación XV — Mia

Invitación digital de quinceañera, hecha con **Next.js**, **TypeScript** y **Tailwind CSS**. El diseño es celestial (noche estrellada) y está pensado para verse primero en el celular.

## Desarrollo

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Contenido del evento

Los textos, fecha, salón, WhatsApp, alias y enlaces están en [`lib/event.ts`](lib/event.ts).

El reproductor espera un archivo en `public/audio.mp3` (no está incluido en el repositorio).
